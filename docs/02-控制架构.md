# 控制架构

一句话：**从上往下五层，每层只能收缩下一层的选择，不能扩大。**

---

## 分层

```
        ┌──────────────┐
        │   行为层      │  想去哪 · 8 Hz · 可以很笨
        └──────┬───────┘
               │ 目标点（可能被否决）
        ┌──────▼───────┐
        │  安全监督器   │  只许否决 · 30 Hz · 不可旁路
        └──────┬───────┘
               │ 允许到达的最近点
        ┌──────▼───────┐
        │   轨迹生成    │  S 曲线 + 落定柔性 · 200 Hz
        └──────┬───────┘
               │ 参考位置 / 速度 / 加速度
        ┌──────▼───────┐
        │ 逆解 + 张力   │  4 线 · 3 自由度 · 1 个冗余
        └──────┬───────┘
               │ 四根线长 / 四根目标张力
        ┌──────▼───────┐
        │   伺服 ×4     │  1 kHz · 电流环
        └──────────────┘

  输入：红外定位（p, v）· 人体来源（禁区）· 力封闭工作空间（边界）
```

### 为什么安全层在那个位置

**它不在行为层里，在它后面。**

如果安全逻辑写在行为层里，它就只是"行为层的一个考虑因素"，写 bug 时会一起错。
放在外面，它是**单向阀**：行为层可以提任何请求，安全层只能把它往下压，不能往上放。

### 优先级（硬）

```
1  不碰到人
2  线不松（否则球失控）
3  到达目标
4  好看 / 顺滑
```

下层的任何收益都不能换上层的一分。

---

## 允许的点集

```
允许 = 力封闭工作空间  ∩  禁区补集
```

这两个都**来自机械，不是软件能绕过的**：

- 力封闭：某根线会松的点，物理上根本到不了
- 禁区：人所在的那个圆柱

所以真正要做的不是"算一条路径"，是**先把这个交集算出来，然后只在里面挑点**。

实测：这个交集只占工位的 **39–40%**（z = 1250 与 1400 两层），且集中在偏高处。

## 张力分配（唯一有真数学的部分）

### 题目

四个人抬一张桌子。桌子要停在确定位置，这是三个条件（X/Y/Z）。但你有四个人、四条力。

**三个方程、四个未知数 → 有一整族答案。** 差别只在"谁的胳膊绷得多紧"。

### 解法

四根线从锚点指向吊点，单位方向 `u₁…u₄`。静止时：

```
Σ Tᵢ · uᵢ = W            （W = 重力 + 供电线拉力的反作用）
Tᵢ ≥ 0                  （缆绳只拉不推）
```

解族可以写成一个特解加一个零空间方向：

```
Tᵢ = Tpᵢ + λ · nᵢ       i = 1..4
```

`n` 就是**零空间向量**——给四根线各加一点 `λ·n`，**吊点受力完全不变**，只是内部张力整体上浮或下沉。

`n` 的算法很朴素：四根方向向量里任取三根做叉乘（三阶行列式），得到四个数。

### 选 λ 的规则

沿 `n` 滑动，取**"最松的那根尽可能紧"**的那个 λ（max-min）。这是一个凹凸分段线性函数，最优解必在两条线的交点处，枚举六对交点即可。

### 推论（重要）

这个"最松张力"是位置的函数，而且差异巨大：

| 位置 | 最松张力 |
|---|---|
| 中心、高处 | 2.57 N |
| 侧位、中高 | 1.86 N |
| 贴墙、低处 | < 0.1 N（等于没有） |

所以：**工作空间有两层——"能到的"和"绷得住的"。它们不是一回事。**
第二层只有算过才知道，画图看不出来。

### 工具

```powershell
python tools\tension.py                 # 默认位置
python tools\tension.py -380 520 1370   # 指定吊点坐标
```

输出四根线长、四根目标张力、最松的是哪根、这个点绷不绷得住。

## 禁区

### 三级

| 区 | 范围 | 处理 |
|---|---|---|
| **红 · 禁止** | 脖子为心 r210 的**竖直圆柱**，向上贯穿到顶 + 工作空间外 | 物理上不可进入 |
| **黄 · 高代价** | r210–400 环带、身后 ±100° 之外、距离 < 400 mm | 允许，但代价很高 |
| **绿 · 偏好** | 两侧、距眼 500–900 mm、低于视线 5–20° | 默认待的地方 |

**红区是二元的，黄区是代价。** 这个区别让行为层不用写一堆 if-else，只需要一个打分函数：

```
score(p) = -惊吓(p) - 遮挡(p) + 视野内(p) + 距离合适(p)
```

红区返回 -∞，黄区给负分，绿区给正分。**以后换成机器学习，学的也就是这个打分函数。**

### 为什么是圆柱不是球

用户原话：「我头上看不到」。

**看不见的东西靠近你，就是惊吓。** 这比"会不会撞到"更硬。

代价：球的头顶正上方也是禁区，不能悬在你头顶正中。这个取舍是故意选的。

### 人体来源：先接最笨的

接口只有一个：

```python
person_capsule() -> (center, radius, confidence) | None
```

| 级 | 做法 | 时机 |
|---|---|---|
| L0 | 固定圆柱（人静止） | 现在 |
| L1 | ToF 检测到有东西 → 圆柱跟随，30 Hz 内插 | 第二版 |
| L2 | 深度相机 + 骨骼 | 以后 |

**别为了一个还不存在的检测方案，把上层写死。**

### 安全环频率

**30 Hz**。人体来源可以更慢（10 Hz 也行），30 Hz 是内插出来的。

## 路径

用 A* 在允许区网格上找路。安全是硬约束（红区不可进），**性格体现在代价函数里**。

```powershell
python tools\plan.py
```

实测（左手边 → 右手边，绕头）：

| 走法 | 路径长度 | 离脖子最近 |
|---|---|---|
| 黏人（偏好靠近） | 1073 mm | 215 mm |
| 直给（只看距离） | 1139 mm | 311 mm |
| 稳（重罚低余量） | 1139 mm | 311 mm |
| 怕人（躲远） | 1606 mm | 535 mm |

**注意"直给"和"稳"走的是同一条路，一步不差。**

因为安全区太宽，没得选。**人格只在边界显现。**

推论：**要有人格，路径必须故意低效**——绕远、放慢、贴着走、到了不马上停。

## 速度曲线

同样一段 1139 mm 的路，三种节奏：

| 节奏 | 到达耗时 | 峰值速度 | 前 0.5 秒走了 | 收尾 |
|---|---|---|---|---|
| 匀速（梯形） | 6.13 s | 260 mm/s | 15 mm | 硬停 |
| 柔和（S 曲线） | 5.38 s | 356 mm/s | **6 mm** | 平滑收住 |
| 落定（S + 回弹） | 5.38 s | 356 mm/s | 6 mm | **回弹 4 mm 再停** |

**三个反直觉的点**：

1. **柔 = 更快**。匀速那条把时间浪费在"立刻加速"和"立刻刹车"上
2. **起步 6mm 是"犹豫"的物理量**。不是装饰，是可测量的
3. **回弹 4mm 是"有质量"的证据**。硬停像被钉住，平滑收住像伺服，回弹再停才像活物

这也解释了为什么定点精度要求可以放宽：要的不是 ±0.5mm 锁死，是 **±4mm 的、会呼吸的停住**。

## 失败模式

| 情况 | 行为 |
|---|---|
| 人体传感器掉线 | 冻结 200 ms → **沿来路退回**（不要停在原地，人可能自己走过来撞上） |
| 定位丢失 | 冻结，等定位恢复；超过 3 秒 → 退回待命位 |
| 某根线张力低于阈值 | 优先保张力（降级为"停在原地不动"），不再响应行为层 |
| 球被拿走 | 断电脱开，吊点收拢，进入"空载"状态 |
| 通信中断 | 保持最后一条安全指令；超过 5 秒 → 缓慢退到待命位 |

**注意"停住"不等于"安全"。** 正确动作是"沿来路退回"——那条路刚刚没有人。

## 时间尺度

| 层 | 频率 | 说明 |
|---|---|---|
| 行为层 | 8 Hz | 可以很笨，慢一点没关系 |
| 安全监督 | 30 Hz | 必须比运动快一个数量级 |
| 轨迹 | 200 Hz | S 曲线要平滑 |
| 伺服 | 1 kHz | 电流环 |
| 红外定位 | 60 Hz | 4 信标 + 10 接收口 |
| 人体来源 | 10–30 Hz | 可内插 |
