# CoreBall 接口标准

> v1.1 · 2026-11-19 · 已冻结
> 本文件是正式标准，不是设计讨论。数值以 `tools/interface_spec.py` 为唯一来源；
> 任何兼容件必须满足本文全部强制条款。接口图为 [`interface.svg`](interface.svg)。

所有尺寸单位 mm，角度单位度（°）；另有注明的除外。

---

## 1. 包络

**适用对象（宿主前提）：球径 φ80、分割面 z=−12。** 这两项是球壳本身的前提，
不属于可变更的接口尺寸。

两个井（头顶、脚底）机械上完全相同。

### 1.1 球侧井（母座）

| 项 | 值 | 备注 |
|---|---|---|
| 井径 | φ30.00 | H8（+0.033 / 0） |
| 井深 | 5.00 | ±0.10 |
| 井底平面度 | 0.05 | 全井底 |
| 井口倒角 | 0.8 × 45° | 一圈 |
| 井壁与球心轴同轴度 | φ0.10 | |
| 井环 | 6061 整体井杯，壁厚 0.8 | 井底与井壁一件，压入球壳 |

> **井杯**：井底、井壁、键槽、钢片窝、焊盘位在同一只 6061 杯体上，杯体带内法兰与球壳粘接/压配。
> 键扭矩、磁吸载荷和 3 A 焊盘的热量都经杯体传到壳体，不再由一块悬空的井底板承担。

> **井深基准**：5.00 从**球顶切平面**量起（球坐标 z = +40 / −40），不是从球面与井壁的交线量起。
> 球面在井口处的实际高度为 √(40²−15²) ≈ 37.08，因此井壁圆柱段只有约 2.1 mm。插头端面停在井底上方 0.4，
> 露出球面约 2.9 mm，这是设计姿态，不是装配错误。

### 1.2 载体侧插头（公头）

| 项 | 值 | 备注 |
|---|---|---|
| 插头直径 | φ29.60 | ±0.05 |
| 插头高度 | 4.60 | ±0.05 |
| 单边间隙 | 0.20 | 径向总间隙 0.40 |
| 插入力 | ≤25 N | 含磁吸 |
| 侧向保持 | ≥8 N | 键槽约束 + 磁吸 + O 圈预紧 |
| 插拔寿命 | ≥5000 次 | |

球身上不允许出现任何凸出物：触点、磁铁、键全部在载体插头一侧，球侧齐平。

**两侧分工**：插头侧 = 弹簧针、磁铁、键；球侧 = 齐平焊盘、钢片、键槽。

## 2. 键位与防插反

三个键的间距不等（96° / 128° / 136°），因此只有一种插入角度。

| 项 | 值 |
|---|---|
| 键数量 | 3 |
| 键角度（0° = +X，从 +Z 看逆时针；两个井用同一球坐标系，不从井口翻转视角） | 0° / 96° / 224° |
| 键半径 | 12.6 |
| 键 | 3.0（切向）× 3.0（径向）× 2.0（轴向） |
| 键槽 | 3.4（切向）× 3.4（径向）× 2.0（深） |
| 键在哪一侧 | 键在插头（凸），槽在球井底（凹） |

![](interface.svg)

键高 2.0 = 槽深 2.0 + 插头端面与井底的 0.4 轴向间隙 − 0.4 公差余量。
按井深 ±0.10、插头高 ±0.05 的最坏叠加，键尖仍离槽底 ≥0.25；键不得顶到槽底。

两个井在球坐标系里完全相同，但从球的两头看过去互为镜像：顶部载体与底部载体的插头是
**互为镜像的零件**。同一个插头翻过来插不进另一头——这是离散键位 + 防插反的代价。
顶部插头用浅色外壳/白色丝印，底部插头用深色外壳/黑色丝印，井口旁也标 `TOP` / `BOTTOM`，避免插错。

侧向保持由**键槽约束 + 磁吸 + O 圈预紧**共同提供；插头与井底不接触时，磁吸的侧向保持会显著下降。

## 3. 触点与引脚

六个触点位 60° 均布，焊盘 φ2.5、半径 9.0、齐平井底，镀层 Ni 3 µm + 硬金 1 µm。
焊盘顶面做 R20 微凸 0.05（`PAD_DOME`），pogo 落位时产生 0.2–0.4 mm 的擦拭行程，避免氧化层。
头顶只焊 4 片（受 φ12 四路滑环限制），脚底焊满 6 片。
载体侧为弹簧针（pogo），针筒 φ1.5、行程 2.0、工作压缩 0.8，单针压力 0.8–1.2 N，
单针额定电流 2 A（3 A 连续时两针并联，每针 1.5 A），接触电阻 ≤30 mΩ / 对。

角度一律用**球的坐标系**：0° = +X，从 +Z 看逆时针为正；两个井都按这个坐标系量，不要从井口翻转视角。TX/RX 一律以球为视角命名。

| # | 角度 | 功能 | 头顶（4 片） | 脚底（6 片） |
|---|---|---|---|---|
| 1 | 0° | VBUS 5 V | ● | ● |
| 2 | 60° | GND | ● | ● |
| 3 | 120° | TX（球 → 载体） | ● | ● |
| 4 | 180° | RX（载体 → 球） | ● | ● |
| 5 | 240° | VBUS 5 V（并联） | — | ● |
| 6 | 300° | GND（并联） | — | ● |

- 头顶 4 片 = 位置 1–4，正好对上吊点的四路滑环。
- 脚底 6 片 = 位置 1–6，两路电源并联承担 3 A。
- 位置 5/6 在不焊接的载体上必须空置，**不得短接**。
- 插拔顺序：GND 针 +0.5 最长 → TX/RX 齐平 → VBUS 针 −0.5 最短。

## 4. 磁吸

| 项 | 值 |
|---|---|
| 磁铁在哪一侧 | 插头（载体侧）；球侧只放钢片 |
| 磁铁角度 | 30° / 150° / 270° |
| 磁铁半径 | 10.0 |
| 磁铁 | φ6 × 2.5，N42 NdFeB |
| 球侧钢片 | φ6 × 1，430 不锈钢或 SPCC 镀镍，齐平井底 |
| 脱开力 | 12 ± 2 N（3 颗在 0.4 气隙下；用 0.2 非导磁垫片微调） |
| 摩擦环 | 硅胶 O 圈，中心线 r14.75，线径 0.8；自由外径 15.15，对 φ30 井壁单边过盈 0.15；坐在插头鼻子的 0.4 深环槽里（模型示意不挖槽，实物必须开槽） |

球侧不放磁铁，避免球离开载体后吸附桌面上的金属杂物。

## 5. 供电

| 项 | 头顶 | 脚底 |
|---|---|---|
| 电压 | 5 V ±5%（4.75–5.25 V） | 5 V ±5%（4.75–5.25 V） |
| 连续电流 | 0.4 A | 3 A |
| 峰值 | 0.6 A / 100 ms | 4.0 A / 500 ms |
| 纹波 | ≤100 mVpp | ≤100 mVpp |
| 上电斜率 | 载体侧软启动，浪涌 <2 A / 10 ms | 同左 |
| 方向 | 载体 → 球，球不回灌 | 同左 |

- 球侧 VBUS 串联理想二极管（P-MOS），反接 −5 V 不损坏。
- 球侧 VBUS 对地 100 µF，并做软启动。
- 触点 ESD：接触放电 ±8 kV；TX/RX 各串 22 Ω + TVS 到地，防止热插拔毛刺和静电。
- 脚底 3 A 中预留 0.5 A 给球内缓冲电池充电。

**功率协商**：球在 WHO 应答后比较载体申报的 `draw_mA` 与本端供电能力。
头顶 0.4 A、脚底 3 A；若载体需求超过本端能力，球只供电并回 ERROR，不下发动作，防止 3 A 载体插到顶井后掉电重启。
3 A 载体识别到只有 4 片焊盘时，必须把自己限到 0.4 A。

## 6. 串口

| 项 | 值 |
|---|---|
| 电平 | 3.3 V LVCMOS；载体 RX 必须容忍 3.3 V |
| 参数 | 115200 8N1，无流控 |
| 主从 | 球为主，载体为从 |
| 帧格式 | `A5 5A VER TYPE LEN PAYLOAD CRC16-CCITT` |
| 帧长度 | `PAYLOAD` ≤64 字节 |
| CRC | CRC-16/CCITT-FALSE：poly 0x1021，init 0xFFFF，不反射，xorout 0x0000 |
| CRC 覆盖 | 从 `VER` 到 `PAYLOAD`（不含 `A5 5A`） |
| LEN | 只计 PAYLOAD 字节数（0–64），不含帧头与 CRC |
| WHO 请求 | `A5 5A 10 01 00 CRC`（TYPE=0x01，LEN=0） |
| 类型 | `0x01` WHO / `0x02` CMD / `0x03` STATUS / `0x04` HEARTBEAT / `0x05` ERROR |
| 上电握手 | 球每 100 ms 发 WHO 请求，最多 1 s；启动后 1 s 内不接受 CMD |
| 无应答 | 300 ms 无 WHO 应答 → 判为哑载体，只供电、不下发动作 |
| 心跳 | 双向 200 ms；连丢 3 次 → 载体就地安全停止 |
| 坏帧 | CRC 错或半帧 → 丢弃并重新等下一个 `A5 5A`；连续 3 个坏帧 → 重发 WHO |
| 热插拔 | 触点抖动 <10 ms 视为一次插入；上电后先发 3 次 WHO，再进入正常帧流 |

**WHO 载荷（载体自述）**

| 字段 | 类型 | 说明 |
|---|---|---|
| proto | u8 | 协议版本，v1.1 = `0x10`（高 4 位主版本） |
| class | u8 | 1 吊点 / 2 轨道 / 3 轮式 / 4 机械臂 / 5 四足 / 6 哑载体 |
| axes | u8 | 可控轴数 |
| sensors | u32 位图 | bit0 IMU / 1 里程计 / 2 ToF / 3 深度 / 4 相机 / 5 麦 / 6 电池 |
| draw_mA | u16 | 本载体需要的电流（mA）；超过本端能力则只供电、不动作 |
| battery_mAh | u16 | 自带电池容量，无则 0 |
| vmax | u16 | 最大速度（µm/s 或 mdeg/s，按轴） |
| name | UTF-8 ≤24 字节 | 例如「轮式底盘 · 厨房那只」 |

**CMD 载荷**：`axis(u8) · target(i32，µm 或 mdeg) · vmax(u16) · amax(u16)`
**STATUS 载荷**：`pos(i32) · vel(i16) · fault(u16)`，1–50 Hz 按需上报。
**ERROR 载荷**：`code(u8)`：1 功率不足 / 2 协议错误 / 3 哑载体。

**字节序**：所有多字节字段（u16 / u32 / i16 / i32）一律为**小端**，低字节在前；
u8 与 UTF-8 文本不受影响。**CRC16 也是小端**（低字节在前），与载荷字段一致。

示例：WHO 请求（TYPE=0x01，空载荷）的完整帧为 `A5 5A 10 01 00 CE BC`，
其中 `CE BC` = CRC16-CCITT-FALSE(`10 01 00`) = 0xBCCE 的小端两字节。
参考实现 `tools/protocol.py` 与 `wokwi/protocol.py` 以此为准，`tools/test_protocol.py` 锁住该帧。

## 7. 版本管理

- 机械包络（井径、井深、键位角度、触点角度与半径）**永久冻结**。
- 球径 φ80、分割面 z=−12 是宿主前提（见 §1），不属于接口包络，不随接口版本变化。
- 改包络必须同时换键位，使旧插头物理上插不进去；不允许「看起来一样但电气不同」。
- 协议可升小版本，只允许加字段，不允许改语义。
- 主版本不同 → 只供电，不通信。
- 每次改动在本文第 9 节变更表记一行：版本 / 日期 / 状态 / 改了什么 / 影响哪些件。
