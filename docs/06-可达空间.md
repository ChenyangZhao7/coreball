# 可达空间测试：8 个墙平面锚点

> 2026-11-24 · 脚本：`python tools/coverage.py`（回归：`python tools/test_coverage.py`）
> 约束：所有锚点在**三面墙的墙平面**上；球高于桌子、不碰脖子圆柱、不往人正后方。

## 测试设定

- 目标网格：x −675…675、y 150…1050、z 900…1500，共 240 个有效点；
- 排除：`r < 250`（脖子 r210 + 球半径 40），`y > 900 且 |x| < 350`（人正后方）；
- 8 个锚点，机器每次选 **4 根**支撑（70 组），四根都要 ≥0.30 N；
- 锚点是**墙平面的出线滑轮中心**：后墙 y=12、左右墙 x=±808；z 为 1670 / 1760 / 1849；
- 运行口径按吊点（球心 +160 mm）；3D 指挥页按球心。两列都列出来。

## 结果

| 布局 | 全空间（吊点 / 球心） | 实用区 y 300–900（吊点 / 球心） |
|---|---|---|
| 旧 8 锚（200 mm 横臂，历史） | 49.6% / 62.9% | 67.6% / 85.8% |
| **墙平面 8 锚（2026-11-24）** | **87.1% / 90.0%** | **96.0% / 100%** |
| 8 根全受力（hinge 求解，历史） | 27.5% | — |

墙平面 8 锚的绿 / 黄 / 红（全空间，吊点）：**74.6 / 12.5 / 12.9%**。

## 为什么还差 10%

**四根只拉不推的线，只能让球待在锚点围成的凸包里面。** 墙平面锚点把后墙和侧墙都推到了围板边，所以剩下的红色几乎全是**前开口 `y ≈ 1050` 那一排**——那里没有墙，锚点凸包到 y≈950 就结束了。

- 前开口两侧（y ≈ 1050）不可达，是「前开口不设锚点」的直接代价；
- 另外少数点是贴着脖子圆柱或张力超过 20 N 的边界点。

这不是选绳算法没找对，是几何上无解。

## 要“任何地方”的两条路

1. **前上方加 2 个锚点（前横梁）**：在 z≈1880、y≈1100、x≈±760 加 2 个锚点，吊点覆盖可到约 92.5%，实用区约 97.2%；球心口径接近 100%。需要用户批准前横梁，本版不做。
2. **8 → 12 个墙锚**：全空间只从 87.1% 到约 90%，多 4 套绞盘，不划算。

## 结论

- 墙平面 8 锚、4 根受力：**全空间 87.1%（吊点）/ 90.0%（球心），实用区 96.0% / 100%**；
- 出线滑轮已在墙平面，`y < 217` 不再是凸包外；`y ≥ 250` 只是暂留的行为边界；
- 剩余的 12.9%（吊点）红色主要是前开口 `y≈1050`，加前横梁才能补；
- 8 个位置已替换进 `build_desk_rig.py` / `build_hub.py` / `web/command.html` / `web/control.html`，安全层仍夹在 `y ≥ 250`。
