# 可达空间测试：8 个墙平面锚点

> 2026-11-25 · 脚本：`python tools/coverage.py`（回归：`python tools/test_coverage.py`）
> 约束：所有锚点在**三面墙的墙平面**上；球高于桌子、不碰脖子圆柱、不往人正后方。

## 测试设定

- 目标网格：x −675…675、y 150…1050、z 900–1500，共 240 个有效点；
- 排除：`r < 250`（脖子 r210 + 球半径 40），`y > 900 且 |x| < 350`（人正后方）；
- 8 个锚点，机器每次选 **4 根**支撑（70 组），四根都要 ≥0.30 N；
- 锚点是**墙平面的出线滑轮中心**：后墙 y=12、左右墙 x=±808；前侧两个滑轮内移到 x=±780，避开前立柱；z 为 1670 / 1760 / 1849；
- 运行口径按吊点（球心 +160 mm）；3D 指挥页按球心。两列都列出来。

## 结果

| 布局 | 全空间（吊点 / 球心） | 实用区 y 300–900（吊点 / 球心） |
|---|---|---|
| 旧 8 锚（200 mm 横臂，历史） | 49.6% / 62.9% | 67.6% / 85.8% |
| 墙平面 8 锚（前侧 y=950，历史） | 87.1% / 90.0% | 96.0% / 100% |
| **前角 8 锚（2026-11-25）** | **100.0% / 99.6%** | **100% / 100%** |
| 8 根全受力（hinge 求解，历史） | 27.5% | — |

前角 8 锚的绿 / 黄 / 红（全空间，吊点）：**85.8 / 14.2 / 0%**——没有红点。

> 注：全空间的 100% 是按上面 240 个允许采样点算的；安全层仍夹在 `y ≥ 250`，所以实际可用体积约 0.6 m³（见 `docs/03`）。

## 为什么现在能到 100%

**四根只拉不推的线，只能让球待在锚点围成的凸包里面。** 之前前侧两个锚点停在 y=950，而目标网格最靠你的一排是 y=1050，所以那一排永远在凸包外。

把前侧两个锚点推到**侧墙最前角 y=1100**，凸包边界就覆盖到 y=1100；y=1050 的那一排进入了凸包。前开口中心（`y>900 且 |x|<350`）本来就是“不往人正后方”的排除区，不算在工作区里。

- 不需要前横梁：两个前角锚点仍在侧墙上；
- 前角滑轮内移 28 mm（x=±780），避开前立柱（x=±802…838）；
- 前开口中间仍然空的，人可以正常进出。

## 结论

- 前角 8 锚、4 根受力：**全空间 100.0%（吊点）/ 99.6%（球心），实用区 100% / 100%**；
- 绿 85.8%，黄 14.2%，红 0%；
- 实际可用体积约 **0.6 m³（600 L）**，是这套工位在 8 个墙锚下的上限；
- 8 个位置已替换进 `build_desk_rig.py` / `build_hub.py` / `web/command.html` / `web/control.html`，安全层仍夹在 `y ≥ 250`。
