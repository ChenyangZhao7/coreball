## 2026-11-26 · 动态仿真（C 方案）

**做了什么**：新增 `tools/dyn_params.py` / `dyn_model.py` / `dyn_control.py` / `dyn_scenarios.py` 和 `tools/test_dyn.py`；`tension.py` 增加 `solve_force(point, W, idx)`。六自由度刚体 + 8 根弹簧-阻尼绳 + 8 个卷筒，200 Hz 外环 / 1 kHz 张力伺服，三个场景（悬停 60 s、三点、0.2 N·s 轻推）+ 球心自旋报告。

**为什么**：实体冒烟测试要回答的三条（漂移 <5 mm、三点不抖、2 s 回位）用静态力平衡答不了；技术报告 §9.2 也明确说旧模型不是六自由度。先在仿真里把参数和失败模式暴露出来，再决定电机、绳和挂点。

**结果**：

- 悬停 60 s：漂移 **1.92 mm**，张力 2.30–2.78 N，无松弛；
- 三点：峰峰 **0.21 mm**，settle **1.42 s**，固定 P0 支撑即可，不需要切换；
- 推一下 0.2 N·s：**0.42 s** 回位，最大偏移 14.2 mm，20 ms 单绳卸载；
- **30 mm 挂点会激出约 5 Hz 张力极限环**（漂移 5.6–7.7 mm、松弛 0.8–4.5 s），10 mm 环/中心眼才稳；
- 运动中切换支撑会产生 200–300 mm 瞬态，v1 默认关闭；
- 最敏感参数是绳有效 EA：×2 时悬停漂移 41 mm，失败；绳阻尼 ×2 时推一下的松弛超 50 ms；
- 性能：60 s 悬停约 5–8 分钟，没达到设计里 <60 s 的批跑目标；单次分析够用，后续要优化几何/可行性投影。

**踩坑**：回位/首次进入时间一开始按绝对时间算，把「2.0 s 时推 + 0.42 s 回位」误报成 2.4 s；改成相对冲量时刻后才是 0.42 s。测试里锁了 `return_time` 必须相对 `t0`。

**验证**：`python tools/test_tension.py`、`python tools/test_dyn.py` PASS；`python tools/dyn_scenarios.py --all --out out/sim` 四个场景落盘；`--sweep` 10 组敏感性表；`python tools/test_coverage.py` 仍 PASS。细节见 `docs/09-动态仿真.md`。

## 2026-11-27 · 操作台方向与朝向修正

- **左右统一为左 = −x、右 = +x**：`body.py` / `blender/actions.json` 和测试一起改；之前动作表把 left 映射到 +x、right 映射到 −x，和 2D 地图、方向键相反。
- **「看我」yaw 修正**：脸窗在球体本地 +Y，Blender 绕 Z 正转会把 +Y 转到 (−sin, cos)，所以 `yaw = atan2(−dx, dy)`；之前用了 `atan2(dx, dy)`，球转向了人的镜像方向。`body.face_yaw()` 现在是一处纯函数，Blender 运行和测试共用。
- **3D 视角改回 180**：试过 210，画面更好看，但方向键的左右会变成斜的；180 正后方，屏幕左右和 x 轴相反。
- **方向键按视图翻转**：3D 工位从人背后看，屏幕左 = +x；2D 地图屏幕左 = −x。`controlVector()` 在 3D 下翻转 x，2D 下保持世界方向，并加测试锁住。
- **演示模式的「看我」也会真的转向人**，不再只换表情。
- **验证**：`tools/test_body.py`、`blender/tests/test_intent.py`、`test_command.py`、`test_bodies.py`、`node --test web/test/*.test.mjs` 全过；浏览器实测左/右各 −/+120 mm，对着人方向 `look` 的 yaw 与预期一致。
