# CoreBall 动态仿真（C 方案）· 设计

> 2026-11-26 · 状态：待批准 · 类型：项目级（纯软件，实体测试前）

---

## 1. 一句话

做一个无头、可复现的动力学仿真：球 + 吊点按六自由度刚体算，8 个绞盘按真实电机/卷筒/绳的参数算，用现有张力分配做控制，然后回答实体冒烟测试的三条——**悬停 60 秒漂移 <5 mm、三点停 5 秒不抖、推一下 2 秒回位**。

## 2. 为什么现在做

- 实体没到，但动态是当前最大的未知；技术报告 §9.2 明确说现有模型只是吊点处的三自由度静力平衡。
- 实体冒烟测试要花 700–1000 元；先在仿真里把「推一下 2 秒回位」「支撑切换会不会甩」这两个问题问清楚，能直接决定电机、绳和挂耳怎么选。
- 仿真参数以后可以拿实体数据回填，不是一次性玩具。

## 3. 方案选择

| 方案 | 内容 | 结论 |
|---|---|---|
| A. 三自由度质点 | 吊点当质点，绳当理想弹簧，PD 控制 | 算不出摆动和姿态，推一下会过于乐观；不选 |
| B. 六自由度刚体 | 球+吊点一个刚体，质心偏 83 mm，绳力汇交在吊点 | 能回答回位，但没有挂耳力矩和卷筒；不够 C |
| **C. 六自由度 + 8 绞盘 + 挂耳/环形导轮 + 电机模型** | 在 B 上加 8 个卷筒状态、绳长、电流/扭矩、耳点力矩 | **选它** |
| D. PyBullet / MuJoCo | 通用引擎 | 缆绳只能拉不能推，接触和约束反而更难调；不选 |

C 的代价是参数更多、更慢，而且很多参数现在只能估。缓解办法：所有参数集中在一个文件里，标注来源和置信度，最后跑敏感性扫描；**不拿调参把阈值调过去**。

## 4. 物理模型

### 4.1 刚体

球 + 吊点当成一个刚体，状态为吊点位置 `r`、速度 `v`、姿态四元数 `q`、体坐标角速度 `ω`。

- 质量 `m = 0.50 kg`；质心在吊点下方 `d = 83 mm`（`BALL_MASS` 口径，docs/03）。
- 转动惯量先估 `I = diag(8.0e-4, 8.0e-4, 4.0e-4) kg·m²`，进参数表，后续用 CAD 或实测替换。
- 球心 = `r + R(q)·(0,0,-0.160)`；**控制与验收都按球心**。
- 张力分配按**吊点**算（和现有 `tension.py`、真实控制器一致）；挂点离吊点 30 mm 的偏差留在 plant 里，作为控制器要承受的力矩扰动，不反馈进分配器。两者相差约 30 mm，不能混用。
- 控制器把球心参考换算成吊点目标：`r_ref = p_ref − R(q)·(0,0,−0.160)`。这里用实测姿态 `q` 做运动学换算，不是姿态主动控制。
- 重力作用在质心；供电线向上 `0.6 N` 作用在吊点；姿态加一个很小的被动阻尼 `-c_rot·ω`（`c_rot = 0.002 N·m·s`，估计）。
- 偏航电机和 ±45 mm 伸缩不建模（见非目标）。

### 4.2 缆绳

8 根绳，绳 i 从锚点 `a_i` 指向挂点 `p_i`：

```
d_i = a_i - p_i
L_i = |d_i|
u_i = d_i / L_i
T_i = max(0, k_i·(L_i - L0_i) + c_i·L̇_i)
```

- `k_i = EA / L0_i`；先取有效 `EA = 6000 N`（Dyneema 本身很硬，实际柔度主要来自端接和导向；**低置信度**），`c_i = 2ζ√(k_i·m/4)`，`ζ = 0.15`。
- `L0_i` 是绞盘放出的自由段长度；`r_i = p_i − r`（吊点到挂点），`L̇_i = −u_i·(v + ω×r_i)`。
  - **注意负号**：`u_i` 从挂点指向锚点，锚点固定，所以挂点朝锚点运动时绳长在缩短。
- 只拉不推：`T_i ≥ 0`；松弛时力为 0，不算负张力。
- 绳质量忽略（0.6 mm Dyneema 约 0.3 g/m）。

### 4.3 绞盘

每个绞盘一个卷筒状态 `θ_i, θ̇_i`：

- 卷筒半径 `r_d = 17 mm`，单层；`L0_i = L0_i0 + r_d·θ_i`。
- 电机 `17HS4401`：保持扭矩 `0.4–0.45 N·m`，转子惯量 `54–68 g·cm²`，额定 `1.5–1.7 A`，相阻 `1.3–1.6 Ω`，相感 `2.8–3.2 mH`（检索值，待 datasheet 核对）。
- 驱动 `TMC2209`：`2 A RMS / 2.8 A 峰值`，`4.75–29 V`，STEP/DIR 1/8–1/64 + 内部 1/256 插值；运行电流先按 `1.2 A RMS` 降额。
- 扭矩常数 `Kt = 0.40 / 1.7 = 0.235 N·m/A`（估算）；`τ_m = Kt·I`，`|τ_m| ≤ 0.4 N·m`，线速度上限 `0.356 m/s → θ̇ ≤ 20.9 rad/s`。
- 卷筒 + 转子惯量 `J = 2.0e-5 kg·m²`（转子 6e-6 + 卷筒约 1.4e-5，估算）。
- 摩擦：库仑 `0.01 N·m` + 粘性 `1e-3 N·m·s/rad`（估计）。
- 电流环一阶滞后 `0.5 ms`；张力环 1 kHz。
- 24 V 电源；本转速下反电势约 2.5 V，先按电流受限处理，不建电压饱和。

### 4.4 挂耳 / 环形导轮（需要拍板）

现在的 CAD 只有 4 个挂耳，方向指向 A1–A4；但运行时默认支撑是 **A2 A3 A4 A6**，而且 8 选 4 会换到任意组合。**4 个固定耳和 8 选 4 不一致**。

仿真提供两种模式：

- `ring`（推荐）：吊点顶部一圈半径 30 mm、z = −1 mm 的低摩擦环形导轮；绳在环上滑到朝向锚点的最近点，力沿绳方向。几何连续，和 8 选 4 兼容。
- `ears4`：按 CAD 的 4 个耳（约 26.6° / 124.6° / 233.2° / 279.0°）固定；每根绳分到角度最近的耳，会算出侧向力和偏心力矩。用来量化「不改成环会多糟」。

物理上建议改成环形导轮（或 8 个小耳），否则默认支撑里的 A6 就已经不在耳的方向上。这个决定不阻塞仿真，但会进设计决定。

### 4.5 支撑切换

三个测试点不可能保持同一组支撑（实测只有极少数点保持 A2 A3 A4 A6）。所以 v1 必须建模切换：

- 支撑监督 30 Hz，打分在**参考点**上做；迟滞：新组分数高出 10% 才换；当前组在**实测点**最松 <0.30 N 时强制换。
- 切换是 300 ms 交叉，权重 `λ` 用 smoothstep 从 0 升到 1：
  - 旧组目标合力 `(1−λ)·W`，新组 `λ·W`；两组各自用 4 线分配器解自己的份额，合力始终是 `W`，不会翻倍。
  - `λ=0/1` 时退化为单组；任一组分不到份额时夹到可行边界并记 `share_deficit`。
- 交叉期间禁止再触发切换；完成后 300 ms 冷却。
- 安全：交叉期间不因「旧组正在卸载」触发 <0.30 N 中止；新组成为当前组后才重新启用。强制切换优先于安全中止，但会记录。
- 切换瞬态照实记录：相对参考的最大偏移、张力跌落、松弛时间、切换次数。

### 4.6 积分

- 半隐式欧拉，`dt = 0.2 ms`；控制外环 200 Hz（每 5 步），伺服 1 kHz（每步）。
- 60 秒 = 30 万步，纯 numpy 向量化，目标在笔记本上 < 60 秒跑完。
- 数值检查：无外力时能量不增长；绳刚度 ×2 时步长减半结果不变（收敛性测试）。

## 5. 控制

沿用 docs/02 的分层，只实现到「逆解 + 张力 + 伺服」：

### 5.1 参考轨迹

- 五次多项式（min-jerk），起止速度和加速度都为 0。
- 峰值速度 `0.356 m/s`，峰值加速度 `1.0 m/s²`；移动时长由距离和这两个上限决定。
- 三点场景每段移动约 2–3 秒，停 5 秒。

### 5.2 外环（200 Hz）

```
o        = R(q)·(0,0,-0.160)
p_ball   = r + o
v_ball   = v + ω×o
e        = p_ref - p_ball
e_v      = v_ref - v_ball
a_cmd    = a_ref + Kp·e + Kd·e_v
F_cmd    = m·a_cmd + (0, 0, m·g - T_UP)
```

- 初始 `Kp = 64 s⁻²`、`Kd = 16 s⁻¹`（ωn ≈ 8 rad/s，临界阻尼），允许在仿真里调，但调参必须记录。
- 不做姿态主动控制：4 根绳只有 3 个力方程，姿态是被动的；只靠耳点力矩和被动阻尼收敛。误差里用实测 `q`/`ω` 只是运动学换算，不产生姿态力矩指令。

### 5.3 张力分配

- 给 `tools/tension.py` 增加任意期望力：`solve_force(point, W, idx=None)`；默认 `W` 仍是重力，旧调用不变。
- 固定当前支撑组，解 4 根目标张力；不可行时取最接近的可行解并标记。
- 期望力超过 20 N 或低于 0.30 N 的组直接判不可行。

### 5.4 伺服（1 kHz）

- 每根主动绳一个张力 PI：`I_cmd = (T_des·r_d + 摩擦前馈)/Kt + Kp_t·(T_des - T_meas) + Ki_t·∫`。
- 初始 `Kp_t = 0.2 A/N`、`Ki_t = 2 A/(N·s)`，抗积分饱和；电流夹在 ±1.2 A。
- 闲散绳目标 0.05 N；测到 >0.15 N 就以 0.05 m/s 放线，避免拖拽。
- 电流环一阶滞后 0.5 ms；扭矩上限和线速度上限硬夹。

### 5.5 安全

- 主动绳张力 <0.30 N 持续 50 ms：中止当前动作，原地保持。
- 任一根 >20 N：降目标张力并记录。
- 不实现碰撞/人体，只做张力安全。

## 6. 场景与验收

| 场景 | 过程 | 指标 | 通过线 |
|---|---|---|---|
| `hover` | 默认位稳定 10 s，再悬停 60 s | 球心最大漂移；RMS；张力 min/max；松弛时间 | 最大漂移 **<5 mm**；无松弛；张力 0.3–20 N |
| `three_points` | P0 → P1 → P2，每段 2–3 s，每点停 5 s | 每点最后 2 s 的峰峰值；settle 时间；切换次数；切换最大偏移 | 峰峰值 **<2 mm**；settle <4.5 s；记录切换瞬态 |
| `push` | 默认位悬停，10 s 时在**质心**加 +x 方向、纯平移冲量 0.2 N·s | 回到 ±5 mm 并保持 0.5 s 的时间；最大偏移；过冲；峰值张力 | 回位 **<2 s**；最大偏移 <80 mm；无松弛 |

三个测试点（球心）：

- `P0 = (-380, 520, 1300)`，支撑 A2 A3 A4 A6
- `P1 = (-180, 520, 1300)`，支撑 A1 A2 A4 A5
- `P2 = (-380, 700, 1300)`，支撑 A2 A4 A5 A6

`push` 的验收冲量是**质心上的纯平移冲量**，不额外加角冲量；0.1 / 0.2 / 0.4 N·s 三档都跑，验收仍以 0.2 为准。

另外跑一个只报告、不验收的 `push_spin`：同样的 0.2 N·s 加在**球心**（离质心 77 mm），会产生约 19 rad/s 的初始自旋，用来观察姿态阻尼够不够；它不参与「2 秒回位」判定，避免把一个手推的旋转误差算成控制器失败。

指标定义：

- **球心** = 吊点 + 体坐标 `(0,0,-0.160)` 旋转到世界。
- **峰峰值** = 窗口内球心三个方向的合成位移的 max−min。
- **settle 时间** = 从移动开始，球心进入目标 ±5 mm 并连续保持 0.5 s 的时间；阈值 4.5 s。
- **悬停漂移** = 10 s 稳定后，球心相对 `P0` 的三维距离；报告 max 和 RMS，阈值 5 mm。
- **回位时间** = 冲量结束后第一次进入目标 ±5 mm 球，并连续保持 0.5 s 的时间；阈值 2 s。
- **过冲** = 第一次越过目标后，沿冲量方向超过目标的最大距离。
- **松弛时间** = 只统计当前主动绳；每根绳 `T<0.30 N` 的累计时间，报告总和与最大值；闲散绳不计。
- **张力范围** = 只统计当前主动绳；阈值 0.30–20 N。
- **切换最大偏移** = 交叉开始到完成后 0.5 s 内，球心相对**当时参考位置**的最大距离；同时另报相对最终目标的最大距离。
- 所有指标写进 `summary.json`，同时打印一张表。

## 8. 文件与接口

```
tools/dyn_params.py       所有参数、来源、置信度
tools/dyn_model.py        刚体 / 绳 / 绞盘 / 积分
tools/dyn_control.py      轨迹 / 外环 / 支撑监督 / 张力分配 / 伺服
tools/dyn_scenarios.py    三个场景、指标、CSV/PNG/summary、CLI
tools/test_dyn.py         回归测试，直接运行打印 PASS
tools/test_tension.py     增加 solve_force 的测试
docs/09-动态仿真.md       方法、结果、敏感性、局限、实体对照清单
out/sim/                  运行产物（不进 git）
```

接口：

- `tension.solve_force(point, W, idx=None, anchors=None) -> dict`，返回与 `solve_subset` 相同结构；`W` 是期望的缆绳合力（N）。
- `dyn_model.Plant(params, support)`：`.state`、`.step(currents, dt)`、`.ball_center()`。
- `dyn_control.Controller(params)`：`.command(plant, t) -> currents`。
- `dyn_scenarios.run(name, params, duration=None) -> dict`。
- CLI：`python tools/dyn_scenarios.py --all --out out/sim`。

## 9. 测试

`tools/test_dyn.py` 直接运行，断言失败即退出：

1. `solve_force` 的四根张力矢量和 ≈ `W`（1e-9）。
2. 平衡点：初始在目标、零速度、目标张力，1 s 后球心漂移 <0.1 mm。
3. 绳只拉不推：把球推向锚点，张力为 0，不出现负值。
4. 绞盘：阶跃电流下卷筒加速、张力上升；扭矩和线速度夹紧。
5. 悬停 10 s：漂移 <1 mm；无松弛。
6. 推一下（质心纯平移 0.2 N·s）10 s 内回位 <2 s。
7. 确定性：同一组参数跑两次，指标逐位一致。
8. 收敛性：绳刚度 ×2、步长减半，指标变化 <5%。
9. 支撑切换：三点场景至少切换 2 次，切换期间相对参考的偏移 <100 mm。

完整 60 s 悬停和 0.1/0.2/0.4 N·s 扫描放在 `dyn_scenarios.py` 的报告运行里，不进快速测试。

## 10. 输出

每次运行写：

- `out/sim/<scenario>.csv`：时间、吊点/球心、速度、姿态、四根张力、线长、电流。
- `out/sim/<scenario>.png`：球心轨迹、张力、姿态三张图。
- `out/sim/summary.json`：参数哈希、指标、阈值、pass/fail、切换次数。
- `out/sim/replay.json`：10 Hz 的遥测快照，字段对齐 `web/control.html` 的 `/state`，以后接 3D 回放（本次不做 UI）。

## 11. 非目标

- 不做偏航电机、±45 mm 伸缩、换载体。
- 不做视觉/红外定位噪声和延迟；先假设状态全知。
- 不做人体/家具碰撞。
- 不做 8 根全主动或六自由度姿态控制。
- 不做实时仿真或 GUI；无头跑批。
- 不改现有 Blender/网页行为；只新增文件和 `tension.py` 的一个可选参数。

## 12. 反目标

- ❌ 为了让三条阈值变绿去调物理参数。
- ❌ 用理想绳/理想电机把问题绕过去。
- ❌ 把仿真结果说成实体验证。
- ❌ 为了「像活物」加控制里没有的阻尼或弹簧。

## 13. 风险与未知

- 参数低置信度：EA、阻尼、惯量、摩擦、Kt 都可能差一倍；靠敏感性扫描和实体回填。
- 4 根线的支撑切换是最大动态风险；交叉切换可能产生下坠或甩动，仿真要如实暴露。
- 挂耳/环形导轮是机械未决项；不解决，8 选 4 的受力方向在实体上不成立。
- 没有姿态主动控制；如果仿真发现球摆得太久，可能需要第五根线或配重，而不是改控制器。
- AS5600 的更新率可能不够 1 kHz 张力环；实体上可能要用 MT6701 或负荷销。

## 14. 已定的实现口径 / 还需要你确认的

**已定（实现层，按这个做）：**

1. 控制与验收用球心，张力分配用吊点；两者相差 160 mm，不能混。
2. 支撑切换 300 ms smoothstep 交叉，新旧组按 `(1−λ)W / λW` 分力；交叉期间不切换，完成后 300 ms 冷却。
3. 三点场景用 P0/P1/P2 强制经历两次支撑切换；切换偏移相对参考算。
4. 悬停/回位/峰峰值/松弛时间/切换偏移的定义按 §6；张力阈值只算主动绳。
5. 挂点默认 `ring`，同时保留 `ears4` 做对比；这是仿真口径，不替实体做决定。

**还需要你确认的只有一条：**

- 「用手轻推一下」的验收口径：按**质心纯平移 0.2 N·s**（不额外加旋转），可以吗？如果你要的是字面「推球面」，球心冲量会产生约 19 rad/s 自旋，那是另一个应力测试；我会照样跑 `push_spin`，但不把它算进 2 秒回位。
